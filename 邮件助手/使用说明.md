# 投递邮件助手

贴一段 JD → DeepSeek 生成主题和正文 → 核对 → 用 QQ 邮箱把简历发出去。

全程在本机运行，网页只监听 `127.0.0.1`。

---

## 一次性配置

### 1. 填 DeepSeek API Key

打开 `邮件助手/config.json`，找到：

```json
"deepseek": {
  "api_key": "",
  ...
}
```

把你的 DeepSeek API Key 填进 `api_key`。**不要把 Key 发到聊天、群里或 GitHub。**

> 模型默认 `deepseek-flash`，接口地址 `https://api.deepseek.com`。
> 费用按 DeepSeek 账户实际计费，写一封邮件通常只有几千 token。

### 2. 确认简历路径

`config.json` 里的：

```json
"resume_path": "C:/Users/你的用户名/Desktop/简历.pdf"
```

如果换了简历，改这一行。路径里的斜杠用 `/` 或 `\\` 都可以。

### 3. 确认发件邮箱

默认复用 `邮箱同步/config.json` 里的 QQ 邮箱和授权码，不需要重复填写。

如果那个文件不在，修改 `mail.config_path` 指向正确的 `config.json`。

---

### 4. 首尾模板（固定不动的部分）

`config.json` 里的 `email_template` 控制邮件的**第一段和最后一段**：

```json
"email_template": {
  "opening": "您好！...看到{company}{position}的招聘信息...",
  "closing": "我的base地点是{base}...简历见附件..."
}
```

- `{company}`、`{position}` 会替换成 JD 里的公司和岗位
- 还支持 `{name}`、`{school}`、`{degree}`、`{undergrad}`、`{base}`、`{availability}`
- 模型**只写中间经历**，不会改写首尾

## 日常使用

1. 双击 `启动邮件助手.bat`
2. 浏览器自动打开看板（`http://127.0.0.1:8766/dashboard`）
3. 点看板顶部的 **✉️ 投递邮件**，面板会在看板里展开
4. 从下拉框选择一条 JD，自动生成主题和正文
5. 核对：
   - 收件邮箱（从 JD 里提取，可能为空，需要手动填）
   - 主题（可改）
   - 正文（可改）
6. 勾选「我已核对」→ 点「确认发送」
7. 看到「已发送给 xxx，并已存入 QQ 邮箱『已发送』」就完成了
   - 如果只显示「已发送」但未能存入，说明邮件已发出，只是 QQ 的 IMAP 追加失败；界面会给出原因

关闭黑色命令行窗口即可停止。

## 安全说明

- **不会自动发送**：必须预览、勾选、再点确认，还会再弹一次确认框
- **一次只发一个收件人**：填多个地址会被拒绝
- **附件固定**：只发送 `resume_path` 指定的那一份 PDF，网页不能指定别的文件
- **附件名按 JD 规则生成**：JD 写了「简历命名为 姓名-学校-专业-岗位」就严格照做；
  JD 没写时才与邮件主题一致；生成后仍可在面板里手动改
- API Key 和邮箱授权码只存在本机，网页代码里没有
- JD 和你的个人资料会发送到 DeepSeek API 用于生成；邮件通过 QQ SMTP 发送

## 常见问题

**页面提示「还没有填 DeepSeek API Key」**
打开 `config.json` 填 `deepseek.api_key`，保存后刷新页面。

**生成时报 401 / 402**
401 是 Key 不对；402 是账户余额不足。到 DeepSeek 控制台检查。

**发送时报「SMTP 登录失败」**
QQ 邮箱授权码过期了。到 QQ 邮箱设置里重新生成，更新 `邮箱同步/config.json` 的 `auth_code`。

**收件邮箱是空的**
JD 里没有写投递邮箱，或写法不常见。手动填一下即可。

**模型写的内容不准确**
它只会使用 `config.json` 里 `profile.experiences` 的事实；如果发现编造，把那段经历写得更明确，或直接改正文。

**端口被占用**
关掉已经运行的助手窗口，或修改 `mail_assistant.py` 里的 `PORT`。
