# 一切顺利 · 求职投递看板

一个**单文件、纯本地**的求职投递管理看板：把每一家公司的投递进度记下来，
用一条流水线看清自己走到了哪一步；再配一个 QQ 邮箱同步脚本，
把「投了简历 / 约笔试 / 约面试 / 发 Offer / 发拒信」自动整理进来。

不需要注册，不需要服务器，没有后端。所有数据都存在你自己电脑上的一个
`我的投递记录.json` 里，想带走就复制这个文件。

> ### 🚀 在线试用
> **https://milkyway668.github.io/everything-goes-well/**
>
> 点开即用，里面是示例数据。你录入的内容只保存在你自己的浏览器里，
> 不会上传，也不会影响其他人。

## 功能

### 一、进度看板

**一条流水线看完整个求职季**

`待投递 → 已投递 → 简历筛选 → 测评 → 笔试 → AI面试 → 一面 → 二面 → 终面 → HR面 → 口头Offer → Offer`，
另有 `已拒绝`、`已放弃` 两档归档。每一档都配了颜色，状态越往后颜色越深。

- **点击进度条或行业条就能筛选**，两个条件可以叠加，再点一次取消
- **四个 KPI**：总岗位数、笔试环节中、面试环节中、Offer 数（带转化率）
- **自动排序**：Offer 在最上面，往下按进度退；已拒绝、已放弃沉到最底，
  不想天天看到的不会占位置
- **待办 DDL 抽屉**：把所有快到期的事按日期排成一条时间轴，填了截止日期的岗位会在列表里高亮
- **时间线**：每条记录都能追加多条进度，改状态不用删了重建，历史都在
- **批量管理**：勾选多条一次性删除
- **新增 / 编辑 / 删除**：公司、岗位、行业、下一步、截止日期、备注

**JD 留存**

看到想投的岗位先把 JD 整段粘进来存着，哪怕原帖过几天关了也不怕。
粘贴框会铺满弹窗，长 JD 也不用在小框里挤；列表按存档时间从新到旧排列，
每条都能一键复制原文。JD 正文里的投递邮箱会自动识别，也可以手动补。

等邮箱同步认到你真投了这家公司，会按「**投递邮箱 + 公司 + 岗位**」匹配，
把 JD 全文写进那条记录的备注里，然后从留存列表移除。两边都有邮箱却对不上时
不会误挂；邮箱对上时，公司/岗位写法不同也能认出来。

**数据放在你自己的文件里**

- 点「连接到数据文件」，选一个 `我的投递记录.json`，之后所有改动直接写进这个文件
- 看板每 8 秒检查一次文件有没有变，脚本写进去的数据会自己出现，不用手动刷新
- 没连文件时退回浏览器 localStorage 兜底，不会因为没保存而丢数据
- 换电脑：把 `我的投递记录.json` 复制过去，打开看板重新连接即可

### 二、QQ 邮箱自动同步（可选）

不用手动录入投递记录。脚本用 IMAP **只读**连上你的 QQ 邮箱：

| 扫描位置 | 识别什么 | 结果 |
|---|---|---|
| 已发送 | 你发出去的简历（收件人是企业邮箱、标题/正文有求职词、带简历附件） | 新建一条「已投递」记录 |
| 收件箱 | 笔试、测评、面试、HR 面、Offer、拒信 | 追加到对应记录的时间线 |

- 公司名从收件人域名反推（`gf.com.cn` → 广发证券），岗位名从正文里抓
- 面试邮件会额外抽出**时间、地点、腾讯会议链接**，写进「下一步」和截止日期
- 扫完先在看板顶部的「📬 邮箱同步 · 待确认」里过目，点「确认写入」才真正进看板，
  点「忽略」就丢掉
- 按邮件 ID 和「公司 + 日期」双重判重，不会重复导入
- 规则是白名单关键词，不调用任何 AI 或第三方服务；Steam 促销、快递通知、电子发票
  这类邮件不会被误认

配置方法见 **[使用指引.md](使用指引.md)**，全程大约 15 分钟。

## 快速开始

1. 下载 `index.html`，用 **Chrome 或 Edge** 打开
2. 首次打开是示例数据，点「清空示例，开始录入」
3. 点顶部「连接到数据文件」，新建一个 `我的投递记录.json`
4. 开始记录。之后每次打开，点「继续使用上次的数据文件」即可

> **浏览器要求**：读写本地文件用的是 File System Access API，目前只有
> Chrome / Edge 支持。Firefox、Safari 只能把数据存在浏览器里，换设备会丢。

### 配置邮箱同步（可选）

1. 安装 Python 3.10 以上（Anaconda 也行）
2. QQ 邮箱网页版 → 设置 → 账号 → 开启 IMAP/SMTP → 生成 16 位授权码
3. 把 `邮箱同步/config.example.json` 复制为 `config.json`，填邮箱和授权码
4. 双击 `1_扫描邮箱.bat`，再回看板点「确认写入」

完整步骤、常见报错、识别规则都在 [使用指引.md](使用指引.md)。

## 隐私

- 没有后端、没有埋点、不向任何服务器上传数据
- 邮箱授权码只存在你本机的 `config.json`，仓库里只有 `config.example.json` 模板
- 邮件只在本机解析；脚本以只读方式打开邮箱，不标已读、不移动、不删除
- `虚拟数据集.json` 里的公司、岗位、备注全部为虚构，不对应任何真实投递

---

## 已知限制

- 看板需要 Chrome / Edge；Firefox、Safari 不支持直连本地文件
- 邮箱同步的 `.bat` 入口只适用于 Windows；Python 脚本本身跨平台
- 只扫描「已发送」和「收件箱」，不看垃圾箱和归档文件夹
- BOSS 直聘、实习僧这类平台代投的邮件，公司名可能只出现在正文里，会进「未匹配」
- 在看板里点「确认写入」是直接改文件，**不会自动备份**；
  用 `2_确认写入看板.bat` 写入则会先自动备份成 `我的投递记录.备份_日期时间.json`

## 技术说明

- 看板：单文件 HTML + CSS + 原生 JavaScript，零依赖、零构建
- 存储：File System Access API 直连 JSON 文件，localStorage 兜底
- 邮箱：Python `imaplib` 只读拉取，正则关键词识别，无第三方服务
- 项目结构、规则词表都在源码里，想改直接改 `sync.py`
