# 一切顺利 · 求职投递看板

一个**单文件、纯本地**的求职投递管理看板：用一条 14 档流水线看清每家公司的进度，
再配两个**可选**的本机助手——QQ 邮箱自动同步、按 JD 生成并发送投递邮件。

看板本身零依赖、不需要服务器，打开 `index.html` 就能用；
两个助手都是本机 Python 脚本，只在你自己的电脑上运行，数据存在本地一个 JSON 文件里。

- **进度看板**：14 档流水线、今日投递一键筛选、DDL 待办、时间线、批量管理
- **JD 留存**：看到想投的先存下来，投了自动写进备注；每条 JD 可一键写求职邮件
- **邮箱同步**（可选）：自动认出简历投递、笔试、面试、Offer、拒信
- **投递邮件**（可选）：按 JD 生成主题与正文，核对后连简历一起发出

> ### 🚀 在线试用
> **https://milkyway668.github.io/everything-goes-well/**
>
> 点开即用，里面是示例数据。你录入的内容只保存在你自己的浏览器里，不会上传。
> 「✉️ 投递邮件」是**演示模式**：可以选一条示例 JD，直接看到一封示例邮件，
> 正文可修改、可复制；真实生成与发送需要下载到本机运行后台，线上不会发出任何邮件。

## 一、进度看板

`待投递 → 已投递 → 简历筛选 → 测评 → 笔试 → AI面试 → 一面 → 二面 → 终面 → HR面 → 口头Offer → Offer`，
另有 `已拒绝`、`已放弃` 两档归档。每一档都配了颜色，状态越往后颜色越深。

- **点击进度条或行业条就能筛选**，两个条件可以叠加，再点一次取消
- **顶部两个紧凑数字**：累计已投递（不含待投递）+ 今日已投递；
  点「今日已投递」的数字能直接筛出今天投出去的岗位，再点一次取消
- **自动排序**：Offer 在最上面，往下按进度退；已拒绝、已放弃沉到最底，
  不想天天看到的不会占位置
- **待办 DDL 抽屉**：把所有快到期的事按日期排成一条时间轴，填了截止日期的岗位会在列表里高亮；
  截止日期过了会自动清掉（岗位记录本身保留），不会一直堆在抽屉底下
- **时间线**：每条记录都能追加多条进度，改状态不用删了重建，历史都在
- **批量管理**：勾选多条一次性删除
- **新增 / 编辑 / 删除**：公司、岗位、行业、下一步、截止日期、备注

## 二、JD 留存

看到想投的岗位先把 JD 整段粘进来存着，哪怕原帖过几天关了也不怕。
粘贴框会铺满弹窗，长 JD 也不用在小框里挤；列表按存档时间从新到旧排列，
每条都能一键复制原文。**点任意一条 JD 卡片可以再次编辑**，改完保存即可，
点弹窗外关闭。JD 正文里的投递邮箱会自动识别，也可以手动补。

等邮箱同步认到你真投了这家公司，会按「**投递邮箱 + 公司 + 岗位**」匹配，
把 JD 全文写进那条记录的备注里，然后从留存列表移除。两边都有邮箱却对不上时
不会误挂；邮箱对上时，公司/岗位写法不同也能认出来。

每条 JD 卡片右侧还有一个「✉️ 写邮件」按钮（需本机邮件助手），
点一下直接跳到这条岗位的写信面板，自动填好收件邮箱并开始生成。

## 三、投递邮件助手（可选，本机运行）

从 JD 留存选一条岗位，后台调用 DeepSeek 生成**主题、正文、附件名**，
核对后勾选确认，通过自己的 QQ 邮箱 SMTP 连简历 PDF 一起发出，
再用 IMAP 存一份到「已发送」。

> 公开演示页没有本机后台，所以是**演示模式**：界面和流程完整，会展示一封示例邮件，
> 但不会真的生成或发送。想实际使用，把项目下载到本机配置后台即可，看板代码完全相同。

- **首尾固定、中间生成**：开头自我介绍和结尾（base、可实习时间）按本地
  `config.json` 里的 `email_template` 固定拼接，模型只写中间的经历段落
- **只用真实信息**：提示词要求只能使用 `profile` 里填写的事实，不许编造经历、数字、证书
- **按 JD 调措辞**：最相关的经历放前面，但不改变事实
- **遵守 JD 的命名规则**：JD 里写了「姓名-学校-专业-岗位」这类附件/主题格式时，
  严格按 JD 的字段顺序和分隔符生成，也可以在面板里手动改
- **发送前必须确认**：勾选「我已核对」+ 二次弹窗，一次只允许一个收件人
- **本地后台**：只监听 `127.0.0.1:8766`，可注册为 Windows 登录自启，正常无需手动打开；
  异常时运行 `邮件助手/启动邮件助手.bat`，日志在 `邮件助手/后台日志.txt`
- 真实 `config.json`（API Key、QQ 授权码、个人资料、简历路径）不入库

## 四、QQ 邮箱自动同步（可选）

不用手动录入投递记录。脚本用 IMAP **只读**连上你的 QQ 邮箱：

| 扫描位置 | 识别什么 | 结果 |
|---|---|---|
| 已发送 | 你发出去的简历（收件人是企业邮箱、标题/正文有求职词、带简历附件） | 新建一条「已投递」记录 |
| 收件箱 | 笔试、测评、面试、HR 面、Offer、拒信 | 追加到对应记录的时间线 |

- 公司名从收件人域名反推（`gf.com.cn` → 广发证券），岗位名从正文里抓
- **地址簿自动学习**：你改正过一次公司名后，脚本记住「收件邮箱 → 公司」，之后同一邮箱直接识别
- 面试邮件会额外抽出**时间、地点、腾讯会议链接**，写进「下一步」和截止日期
- 扫完先在看板顶部的「📬 邮箱同步 · 待确认」里过目，点「确认写入」才真正进看板，
  点「忽略」就丢掉
- 按邮件 ID 和「公司 + 日期」双重判重，不会重复导入；
  如果同一个公司的同一个岗位已经在看板里（日期不同也算），会自动忽略，不打扰你确认
- 规则是白名单关键词，不调用任何 AI 或第三方服务；Steam 促销、快递通知、电子发票
  这类邮件不会被误认

配置方法见 **[使用指引.md](使用指引.md)**，全程大约 15 分钟。

## 五、数据放在你自己的文件里

- 点「连接到数据文件」，选一个 `我的投递记录.json`，之后所有改动直接写进这个文件
- 看板每 8 秒检查一次文件有没有变，脚本写进去的数据会自己出现，不用手动刷新
- 没连文件时退回浏览器 localStorage 兜底，不会因为没保存而丢数据
- 换电脑：把 `我的投递记录.json` 复制过去，打开看板重新连接即可

## 快速开始

### 只想用看板（1 分钟）

1. 下载 `index.html`，用 **Chrome 或 Edge** 打开
2. 首次打开是示例数据，点「清空示例，开始录入」
3. 点「连接到数据文件」，新建一个 `我的投递记录.json`
4. 开始记录。之后每次打开，点「继续使用上次的数据文件」即可

> **浏览器要求**：读写本地文件用的是 File System Access API，目前只有
> Chrome / Edge 支持。Firefox、Safari 只能把数据存在浏览器里，换设备会丢。

### 再加邮箱同步（约 15 分钟）

1. 安装 Python 3.10 以上（Anaconda 也行）
2. QQ 邮箱网页版 → 设置 → 账号 → 开启 IMAP/SMTP → 生成 16 位授权码
3. 把 `邮箱同步/config.example.json` 复制为 `config.json`，填邮箱和授权码
4. 双击 `1_扫描邮箱.bat`，再回看板点「确认写入」

完整步骤、常见报错、识别规则都在 [使用指引.md](使用指引.md)。

### 再加投递邮件助手（可选）

1. 申请一个 DeepSeek API Key
2. 把 `邮件助手/config.example.json` 复制为 `config.json`，
   填 Key、个人资料、简历路径和邮件首尾模板
3. 打开看板，点顶部「✉️ 投递邮件」，或在任意 JD 卡片点「✉️ 写邮件」
4. 后台没在运行时，双击 `邮件助手/启动邮件助手.bat` 一次即可

## 隐私

- **看板本体**：没有后端、没有埋点，数据只在你浏览器或你选的 JSON 文件里
- **邮箱同步**：邮件只在本机解析；脚本以只读方式打开邮箱，不标已读、不移动、不删除
- **投递邮件助手**：只有在你点「生成」时，才会把 **JD 文本和 `config.json` 里的个人资料**
  发送到 DeepSeek API 用于写邮件；生成好的邮件通过你自己的 QQ 邮箱发出。
  不启用这个助手，就不会有任何外部请求
- API Key、QQ 授权码只存在你本机的 `config.json`，仓库里只有 `config.example.json` 模板
- 公开网页版保留「投递邮件」「写邮件」按钮，但线上没有本机后台，点击只会弹一句提示，
  不会向 `127.0.0.1` 或任何服务器发请求；其余操作都只发生在访客自己的浏览器里
- `虚拟数据集.json` 里的公司、岗位、备注全部为虚构，不对应任何真实投递

## 已知限制

- 看板需要 Chrome / Edge；Firefox、Safari 不支持直连本地文件
- 邮箱同步的 `.bat` 入口、邮件助手的登录自启只适用于 Windows；Python 脚本本身跨平台
- 只扫描「已发送」和「收件箱」，不看垃圾箱和归档文件夹
- BOSS 直聘、实习僧这类平台代投的邮件，公司名可能只出现在正文里，会进「未匹配」
- 在看板里点「确认写入」是直接改文件，**不会自动备份**；
  用 `2_确认写入看板.bat` 写入则会先自动备份成 `我的投递记录.备份_日期时间.json`
- 投递邮件生成需要 10–30 秒（调用 DeepSeek），且一次只发一个收件人，发送后无法撤回

## 技术说明

- 看板：单文件 HTML + CSS + 原生 JavaScript，零依赖、零构建
- 存储：File System Access API 直连 JSON 文件，localStorage 兜底
- 邮箱：Python `imaplib` 只读拉取，正则关键词识别，无第三方服务
- 邮件助手：Python 标准库 HTTP 服务（仅监听 `127.0.0.1:8766`）+ DeepSeek API + QQ SMTP/IMAP
- 项目结构、规则词表都在源码里，想改直接改 `sync.py` / `mail_assistant.py`

版本变化见 [CHANGELOG.md](CHANGELOG.md)。
